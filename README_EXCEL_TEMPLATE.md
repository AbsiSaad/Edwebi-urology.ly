# ملف Excel لإدخال البيانات الثابتة - Healthcare
# Excel Template for Healthcare Master Data Input

## 📁 الملفات المتوفرة

1. **healthcare_master_data_template.xlsx** - ملف Excel بأوراق متعددة (مُوصى به)
2. **healthcare_master_data_template.csv** - ملف CSV (بديل)
3. **HEALTHCARE_DATA_INPUT_GUIDE.md** - دليل مفصل لإدخال البيانات

---

## 📋 كيفية الاستخدام

### الخطوة 1: فتح الملف
- افتح ملف `healthcare_master_data_template.xlsx` في Microsoft Excel أو LibreOffice Calc

### الخطوة 2: إدخال البيانات
- كل ورقة (Sheet) تحتوي على نوع مختلف من البيانات
- الحقول المميزة بـ * (نجمة) هي حقول إلزامية
- املأ البيانات حسب الأمثلة المذكورة

### الخطوة 3: الحفظ
- احفظ الملف بعد إدخال جميع البيانات
- يمكنك إرسال الملف إلى فريق IT

---

## 📊 الأوراق المتوفرة في ملف Excel

1. **Medical Department** - الأقسام الطبية
2. **Healthcare Practitioner** - الممارسين الصحيين
3. **Appointment Type** - أنواع المواعيد
4. **Service Unit Type** - أنواع وحدات الخدمة
5. **Service Unit** - وحدات الخدمة
6. **Practitioner Schedule** - جداول الممارسين
7. **Lab Test Template** - قوالب الفحوصات المخبرية
8. **Medication** - الأدوية
9. **Clinical Procedure** - الإجراءات السريرية
10. **Diagnosis** - التشخيصات
11. **Complaint** - الشكاوى

---

## ⚠️ ملاحظات مهمة

1. **لا تحذف الصف الأول** (رؤوس الأعمدة)
2. **الحقول المميزة بـ * إلزامية**
3. **استخدم الأمثلة كمرجع**
4. **للأوقات:** استخدم الصيغة 24 ساعة (09:00:00)
5. **للألوان:** استخدم كود hex (#4285F4)
